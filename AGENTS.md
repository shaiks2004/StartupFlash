# AGENTS.md

## Project

Startup Flash is a premium startup and technology news platform.

Stack:

* React 18
* Vite
* Express
* WordPress REST API

## Do

* Preserve existing architecture
* Preserve SEO implementation
* Use reusable components
* Use design tokens
* Use Lucide icons
* Keep diffs small
* Maintain responsive layouts

## Don't

* Don't rewrite the project
* Don't add heavy UI frameworks
* Don't replace WordPress
* Don't hardcode API URLs
* Don't break existing routes

## Design Rules

* Premium editorial look
* Consistent spacing scale
* Consistent shadows
* Consistent radius tokens
* Accessible interactions
* Mobile-first

## Performance

* Lazy load routes
* Lazy load images
* Use skeleton loaders
* Respect prefers-reduced-motion

## Commands

npm run dev
npm run build
npm run lint

Always run build before finishing tasks.
